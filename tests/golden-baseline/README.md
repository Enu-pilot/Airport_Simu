# ゴールデンの基準値の保存と比較

ゴールデン（`tests/golden/`）を更新する前後の実測値を保存し、差分を確認するための場所。手順は docs/42 §5。

- `<日付>_<名前>/actual/` … その時点のコードで採取した実測値（期待値と異なるファイルだけ）。`README.md` に差分の概要。
- `capture-actual.sh <出力先>` … リポジトリを変更せずに実測値を採取する（HEAD の複製を作り、その中で `GOLDEN_UPDATE=1` を実行する。未コミットの変更は含まれない）。
- `compare.py <期待値のディレクトリ> <実測値のディレクトリ>` … 項目ごとの差分を Markdown で出力する。

`tests/golden/` 自体は、差分と根拠を提示して承認を得るまで更新しない（CLAUDE.md §3）。
