# 06. UI設計書

## 1. 原則

- UI はシミュレーション状態を **読み取り専用の表示モデル**（セレクタ経由）で参照し、変更はすべてコマンド送信で行う。
- 数値（収支・KPI・予測）はコアが計算し、UI は書式化（桁区切り・単位・色）のみを担当する。
- マップ表示（Canvas/WebGL）と HUD・パネル（DOM）を分離する。
- 状態は色だけでなくアイコン・パターンでも示す（色覚多様性対応）。

## 2. 画面一覧

| 画面 | 内容 |
|------|------|
| タイトル | 新規ゲーム / ロード / 設定 / クレジット |
| 新規ゲーム設定 | モード、マップ（初期版は1種）、初期資金、シード、イベントON/OFF |
| メイン画面 | マップ + HUD + ツールバー + パネル群（下図） |
| 設定 | 音量（後続）、UI拡大率、スクロール速度、オートセーブ間隔 |

## 4. マップビュー

### 4.1 操作

| 操作 | 動作 |
|------|------|
| 右ドラッグ / 中ドラッグ / WASD・矢印 | パン |
| ホイール / Q・E | ズーム（5段階、タイル 8px〜64px） |
| 左クリック | 選択（航空機・施設・旅客グループ・スポット） |
| 建設ツール中の左ドラッグ | 配置（ペイント系は塗り、矩形系は範囲、滑走路は始点→終点） |
| R | 回転（配置前） |
| Esc / 右クリック（ツール中） | ツール解除 |
| Space | 一時停止切替 |
| 1〜4 | 速度 1x/2x/4x/8x |
| Ctrl+Z | 建設の取り消し（一時停止中、後続） |

### 4.2 建設時のフィードバック

- ゴースト表示: 配置可能=緑、不可=赤＋理由ツールチップ（「水域には建設できません」「滑走路クリアランス内です」等）。
- 費用プレビュー: カーソル付近に合計建設費と工期。
- 接続プレビュー: 誘導路を引いている間、接続されるノードを点で表示。滑走路に接するとホールディングポイントのアイコンが出る。
- 配置確定後、検証警告があれば黄色の警告アイコンを該当箇所に表示。

### 4.3 描画レイヤー（下から）

1. 地形
2. ペイント系（エプロン → 誘導路 → 道路）、滑走路
3. 建物・スポット・ゲート
4. 動的オブジェクト（GSE車両 → 航空機 → 旅客ドット）
5. オーバーレイ（ヒートマップ・経路線・予約ハイライト）
6. 選択枠・ゴースト・警告アイコン

### 4.4 オーバーレイ

| オーバーレイ | 表示内容 |
|-------------|---------|
| 混雑 | 施設の待ち行列長をヒートマップ、誘導路の待機機体を赤点 |
| 経路 | 選択した航空機の予定経路と予約済みノード |
| スポット | スポットごとの区分・割り当て状況（ガントへのリンク） |
| 稼働率 | 施設ごとの稼働率（緑/黄/赤 + 数値ラベル） |
| デバッグ | エアサイドグラフ（ノード・有向エッジ・maxSize）、予約、状態名、ID（開発ビルド/設定で有効化） |

### 4.5 航空機の表示

- 区分ごとにサイズの異なるトップダウンシルエット。航空会社色の尾翼。
- 状態アイコン: 待機中（⏸）、遅延（⏱）、経路なし（⚠）。
- 補間: シミュレーションのティック間は描画側で線形補間（シミュレーション状態は変更しない）。

## 5. パネル

### 5.1 運航表（フライトボード）

- 到着/出発タブ。列: 便名・航空会社・機種・予定・予想・実績・スポット/ゲート・状態・遅延理由。
- 行クリックで機体を選択しマップをフォーカス。
- フィルタ: 遅延のみ / 航空会社 / 時間帯。

### 5.2 スポット割り当てガント

- 縦軸スポット、横軸時刻（24時間）。ブッキングを帯で表示、遅延は帯の延長を斜線で。
- ドラッグで割り当て変更（検証に失敗すると戻る）。（S優先度）

### 5.3 航空会社・契約

- 提案一覧: 航空会社、路線、機材、週便数、時間帯、割引要求、**推定効果**（日次旅客増、日次収入増、ピーク負荷の変化）。承認/拒否ボタン。
- 契約中一覧: 満足度メーター（数値+バー）、満了日、主な不満要因トップ3。

### 5.4 財務

- 当日・昨日・過去30日の収支（カテゴリ別積み上げ棒グラフ）。
- 料金設定（スライダー + 数値入力。基準料金比と予想される需要影響を表示）。
- 融資（S優先度）。

### 5.5 職員

- 施設種別ごとに配置人数と必要人数の目安（ピーク需要から算出）、日次人件費。

### 5.6 KPI ダッシュボード

- [05_economy_spec.md](05_economy_spec.md) §10 の KPI を数値タイル + 過去30日の折れ線で表示。

### 5.7 詳細パネル（選択対象）

| 対象 | 表示 |
|------|------|
| 航空機 | 便名・機種・状態と経過時間・現在の待機理由・ターンアラウンド作業の進捗（作業ごとのバー） |
| スポット | 区分・紐付けゲート・今日のブッキング一覧 |
| 処理施設 | 窓口数・配置人数・待ち人数・平均待ち時間・稼働率、職員増減ボタン |
| 滑走路 | 運用モード・使用方向・直近1時間の運用回数・進入キュー |
| 旅客グループ | 便・人数・段階・待ち時間・満足度 |

### 5.8 通知・イベントログ

- 重要度: 情報 / 注意 / 警告。警告（経路なし、デッドロック、スポット不足、破産接近）はトースト表示 + クリックで該当箇所へ移動。
- ログはフィルタ可能。

## 6. 開港前のガイド

- 開港条件（[02](02_game_spec.md) §6）をチェックリスト表示し、満たしていない項目をクリックすると該当ツールを選択する。

## 7. 技術的な実装方針（UI）

- HUD・パネルは React。マップは PixiJS のキャンバスを React コンポーネント内にマウントし、描画ループは React の再レンダリングと独立させる。
- UI の状態購読は、ティックごとではなく **最大10Hz** にスロットルしたスナップショット（表示モデル）で行い、React の再描画コストを抑える。
- UI文字列は `src/ui/i18n/ja.json` に集約する。
