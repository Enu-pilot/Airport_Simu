# 17. 機種と施設の適合性（Phase 7）

実装: `src/core/aircraft/compat.ts`。運航計画（`economy/planning.ts`）、運航（`sim/simulation.ts` のスポット・滑走路の割り当てと経路）、
分析（`ui/AnalysisPanels.tsx` の適合性分析）、機種カタログ画面はすべてこのモジュールの判定を使う（判定を重複して実装しない）。

> ゲームで採用した簡略化ルールであり、実際の空港運用・航空安全基準への適合を保証するものではない。

## 判定結果

- **ok**: 使える / **ng**: 使えない（理由つき）/ **unknown**: 判定に必要な情報が足りない（要確認）
- 機種データがない（未解決の機種 ID）ときは、どの施設も `unknown`（`TYPE_UNRESOLVED`）。

## ルール

| 対象 | 条件（すべて満たせば ok） | 理由コード |
|---|---|---|
| 滑走路 | 運用中 | `NOT_OPERATIONAL` |
| | 滑走路の区分（長さ・幅から決まる S/M/L）≥ 機体の区分 | `RUNWAY_CLASS` |
| | 長さ ≥ 離陸に必要な長さ（浮揚までの距離 + 100 m、ゲーム値） | `RUNWAY_TAKEOFF_LENGTH` |
| | 長さ ≥ 着陸に必要な長さ（必要減速距離 + 200 m、ゲーム値） | `RUNWAY_LANDING_LENGTH` |
| | コード F の機体は舗装幅 60 m | `RUNWAY_CODE_F` |
| 駐機スポット | 運用中、区分 ≥ 機体の区分 | `NOT_OPERATIONAL` / `STAND_CLASS` |
| | コード F の機体は L 級かつ「コード F 対応」 | `STAND_CODE_F` |
| | 誘導路につながっている | `STAND_NOT_CONNECTED` |
| 誘導路 | 幅の区分 ≥ 機体の区分、コード F の機体は「コード F 対応」 | `TAXIWAY_CLASS` / `TAXIWAY_CODE_F` |
| 搭乗ゲート | 紐付いたスポットがある（ない場合は unknown） | `GATE_NO_STAND` |
| | 紐付いたスポットが使える | `GATE_STAND_NG` |
| | 2 階建て機（A380）の上階への搭乗橋はモデル化していない（情報。使える） | `GATE_UPPER_DECK` |
| 地上支援 | 必要な車両・作業員が空港に 1 台以上 | `GSE_NONE`（ng） |
| | 必要数より少ない（時間がかかるが使える） | `GSE_FEWER`（ok） |
| | 燃料施設がある | `NO_FUEL_FARM` |
| 空港全体 | 使える滑走路とスポットを結ぶ経路がある | `NO_ROUTE` |

### 機体の区分（翼幅 → コード文字 → S/M/L）

- 翼幅からコード文字（ICAO Annex 14 の翼幅区分を参考: A < 15 m、B < 24 m、C < 36 m、D < 52 m、E < 65 m、F < 80 m）。
- 実在機種: コード C 以下 = **M**、D・E = **L**、F = **L ＋ コード F**。翼幅が未設定の機種は安全側（L ＋ コード F）。
- 旧形式の汎用機材は Phase 2 以来の区分（regional70 = S、narrow180 = M、wide300 = L）。
- 例: ATR 72-600・E190・A321・737 = M、767・787・777・A350 = L、A380 = L（コード F）。777-300 は翼幅 60.93 m（E）、777-300ER は 64.8 m（E）。

## 運航への反映

- スポットの割り当ては `checkStand` が ok のスポットだけ（閉鎖・障害中のスポットは除外、ゲート故障中のスポットは後回し）。
- 滑走路は `checkRunway` が ok の滑走路だけ（閉鎖中は除外）。経路探索は区分とコード F の条件を満たす誘導路だけを使う。
- 運航計画の分析は、その空港で運航できない機種の便をエラー（区分非対応）として示し、スポットの仮割り当てにも同じ判定を使う。
- 地上支援の必要数・作業時間は機種ごと（`sim/tasks.ts`）。車両が必要数より少なければ時間が延びる（`GSE_FEWER`）。
- バスゲート（`boardingMode: 'bus'`）の `checkGate` は、スポットを見ずに運用中なら ok（理由 `GATE_BUS`、情報）。運用中でなければ ng（`NOT_OPERATIONAL`）。ランプバスは `airportUnits` に数える（docs/29）。
- 不変条件 S3: スポットに駐機している機体は、そのスポットの判定が ok。
