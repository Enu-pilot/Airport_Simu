# 羽田空港の施設・設備調査（設計参考資料）

- 作成日: 2026-11-18
- 対象: 東京国際空港（羽田空港）
- 文書種別: 外部調査・設計参考資料
- 位置づけ: Airport_Simu の施設体系を検討する参考資料。現行実装仕様・実装計画・羽田空港の完全な設備台帳ではない。

## 1. 目的

羽田空港を題材に、空港を構成する施設・設備を用途別に整理する。旅客ターミナルの目に見える設備だけでなく、航空機整備、グランドハンドリング、手荷物、貨物、空港アクセス、管制・航空保安、エネルギー、防災、環境、従業員施設までを対象とする。

本書は、Airport_Simu の施設カテゴリ、建設候補、処理能力モデル、設備間依存関係を検討する際の調査資料として使用する。列挙した設備をすべて実装する決定ではない。

## 2. 調査上の前提と確度

空港の制限区域内設備、事業者専用施設、機器の台数・能力・正確な配置は、公開資料だけでは全容を確認できない。そのため、以下の区分を用いる。

| 表記 | 意味 | 取り扱い |
|---|---|---|
| **[羽田確認]** | 羽田空港または羽田空港内の施設として、国・空港公式・施設所有者等の公開資料で確認できる | 羽田の施設構成を説明する根拠にできる |
| **[羽田サービス確認]** | 羽田空港公式の旅客ターミナル案内・サービス一覧に掲載されている | ターミナル利用者向け設備・サービスとして扱う |
| **[一般設備]** | 国土交通省等が空港業務・グランドハンドリングの一般的な設備・作業として説明しているが、羽田での設置場所・台数までは確認できていない | Airport_Simu の一般的な建設候補。羽田に実在すると断定しない |
| **[要個別確認]** | 機能上は想定できるが、今回確認した公開資料では羽田での設置を確認できていない | 実在施設としての断定や数値設定を避ける |
| **[整備・計画情報]** | 公的資料で整備・再編・導入計画が公表されている | 供用済みと計画中を区別する |

### 2.1 羽田空港の全体像

- [羽田確認] 羽田空港は4本の滑走路と3つの旅客ターミナルを有する。
- [羽田確認] 空港には旅客ターミナルだけでなく、滑走路・誘導路・エプロン、整備地区、貨物地区、管理・インフラ施設等が配置されている。
- [羽田確認] 国土交通省の施設紹介では、整備地区に格納庫、ラインストア、車両整備工場、エアポートクリーンセンター、エネルギーセンター、電気供給施設が紹介されている。
- [羽田確認] 貨物ターミナル地区には航空会社上屋、郵便上屋、代理店上屋、カーゴセンター、機内食工場等が紹介されている。
- [羽田サービス確認] 旅客ターミナル公式サイトでは、案内、銀行・ATM、宅配・手荷物、バリアフリー、ラウンジ、宿泊、診療、子ども向け設備、通信、会議・MICE、ビジネスジェット等が案内されている。
- 数値・台数・能力は、対象年度・対象区域・集計方法が確認できる場合に限って採用する。本書は施設の種類を整理するもので、処理能力の実測値を定義しない。

## 3. 施設・設備の分類

分類は建物の用途だけでなく、施設が提供する機能・処理工程を基準にする。1つの建物に複数の機能が入る場合や、建物内に設備が置かれる場合があるため、建物カテゴリと内部設備カテゴリは同一視しない。

### 4.3 能力評価と依存関係

空港全体の能力を単純に施設数の合計で扱わず、旅客・航空機・手荷物・貨物それぞれの流れに沿って評価する。

| 能力領域 | 主な工程・設備 | 能力の単位候補 | 代表的なボトルネック |
|---|---|---|---|
| 航空機運航 | 滑走路、誘導路、管制、スポット | 発着回/時、同時駐機機数 | 滑走路間隔、地上走行、スポット占有 |
| 折り返し | 給油、清掃、ケータリング、搭降載、整備、プッシュバック | 機種別の機/時、作業完了時間 | 車両数、作業員数、同時作業制約 |
| 旅客出発 | アクセス、チェックイン、保安検査、出国審査、搭乗 | 人/時 | レーン数、窓口数、歩行経路、要員 |
| 旅客到着 | 降機、入国審査、手荷物受取、税関、アクセス | 人/時 | 審査ブース、手荷物返却、通路 |
| 手荷物 | 受託、検査、仕分け、メイクアップ、搬送 | 個/時、便/時 | 検査装置、仕分け能力、搬送経路 |
| 貨物 | 受託、検査、保管、ULD組立、搬送 | t/日、ULD/時 | 上屋面積、荷役機材、保管温度、車両 |
| アクセス | 鉄道、バス、道路、駐車場 | 人/時、台/時 | 駅ホーム、バス乗降場、道路区間、駐車容量 |
| ライフライン | 電力、燃料、熱、水、通信 | kW、供給量/時、容量 | 受変電、配管、ポンプ、供給経路 |

能力値を設定する場合は、根拠のない数値を実在値のように置かない。実機・公的資料に根拠がある値、ゲーム内バランス値、未算出を区別する。

### 4.4 ボトルネックを判定する考え方

- 施設単体の理論能力だけでなく、前後工程の接続・搬送能力を確認する。
- 能力があっても、必要な要員・車両・電力・燃料・保管スペースが不足すれば処理できない。
- 車両・固定設備は、同時に複数の航空機・旅客・貨物へ割り当てられない場合がある。稼働時間と移動時間を考慮する。
- 複数のターミナルが設備・人員・道路・鉄道を共有する場合、ターミナル単位と空港全体の集計を分ける。
- 建設中・閉鎖中・故障中・接続未完了の設備は、稼働能力に含めない。
- 建物の内部に置かれた設備は、外部ネットワークへの接続が未モデル化なら、能力を過大評価しない。
