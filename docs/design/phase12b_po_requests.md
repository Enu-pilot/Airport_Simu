## 追加要望（2026-11-13）: リモートスポット・搭乗バスゲート（12B-3a に取り込む）
目的: ターミナルに接続していない独立搭乗ゲート、およびリモートスポットへの搭乗バスを実装し、現実的な空港運用を再現する。まずリポジトリ全体を調査して実装計画を作成。
1. 搭乗方式の拡張: 既存の `gate` 施設を維持。搭乗方式 `contact`（通常搭乗）と `bus`（バス搭乗）を追加。既存データで未設定は `contact`。将来の独立ゲート・サテライトターミナルへの拡張を考慮。
2. バス搭乗: ターミナルの搭乗ゲートからバス乗り場へ旅客を誘導。バスの定員・台数・乗車時間・移動時間・降車時間を管理。リモートスポットで降車後に航空機へ搭乗。到着便では航空機からターミナルへのバス輸送も対象。バス不足・故障時の待機・遅延・乗り遅れを適切に処理。
3. 独立搭乗ゲート: ターミナルに隣接しないゲートを配置可能に。ゲートと接続先施設を明示的に管理。旅客がターミナルから独立ゲートへ移動できる経路を検討。既存のターミナル内旅客経路との整合性を保つ。
進め方の決定: 12B-3a まで完了した時点で PR。その後 12B-3b・12B-4 を別 PR。
