3. 修正した不具合の再現テストを `tests/audit/known-issues/`・`tests/audit/e2e-known/` から通常のテスト群（`tests/unit/`・`tests/e2e/`）へ移す。
4. シミュレーションに触れた変更: 決定性（同じシードで同じ結果）、不変条件、保存 → 復元 → 継続が連続実行と一致。
5. 新しい設定を持たない保存データが読み込め、従来どおり動く。不具合修正で結果が変わる場合は §5 に従う。
6. 新機能は opt-in。正常系・境界値・異常系・回帰のテストを付ける。

## 5. ゴールデンと版の扱い（2026-11-16 承認済みの 3 段階）
