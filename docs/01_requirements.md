# 01. 要件定義書

## 1. 目的

PCブラウザで動作する、空港を自由に設計して運営するシミュレーションゲーム「SkyPort」を開発する。
建物や道路の配置が、航空機・旅客・手荷物の流れに実際に影響することを中核体験とする。

### 1.1 プレイヤー体験の目標

- **設計の手応え**: 誘導路の引き方ひとつで地上走行時間や滑走路の処理能力が変わる。
- **流れの可視化**: 混雑・待ち行列・遅延の原因がマップ上で見える。
- **経営判断**: 限られた資金で「どこを拡張すれば収益とサービス水準が上がるか」を考える。
- **改善ループ**: 運航実績と収支を見て、ボトルネックを特定し、再設計する。

### 1.2 非目標（スコープ外）

- 実際の航空管制・航空安全基準（ICAO / FAA / 国内法規）への適合保証。
- 実在の航空会社・空港・機体メーカーの商標を用いた再現。
- 飛行中のフライトシミュレーション（空中は抽象化する）。
- マルチプレイヤー、オンラインランキング（初期版）。
- スマートフォン・タブレット対応（初期版）。

## 2. 対象ユーザー・動作環境

| 項目 | 要件 |
|------|------|
| 対象 | 経営・建設シミュレーション愛好者（Cities: Skylines, Airport CEO, SimAirport 等のプレイヤー層） |
| プラットフォーム | PCブラウザ（Chrome / Edge / Firefox の最新版。Safari は努力目標） |

## 4. 非機能要件

| ID | 区分 | 要件 |
|----|------|------|
| NF-01 | 性能 | 初期版目標規模（滑走路2本・スポット30・同時航空機40機・同時旅客グループ2,000）で 60fps 描画、8x 速度でシミュレーションが実時間に追従する |
| NF-02 | 性能 | 初回ロード 5秒以内（一般的なブロードバンド、gzip後バンドル 2MB 以下目標） |
| NF-03 | 決定性 | 同一のセーブデータ・同一シード・同一コマンド列からは、同一のシミュレーション結果が得られる（同一ブラウザ・同一ビルドにおいて） |
| NF-04 | 分離 | シミュレーションコアは DOM / 描画 API / 実時間に依存しない（Node 上で単体実行できる） |
| NF-05 | 堅牢性 | 不変条件（スポット二重割り当て禁止、滑走路排他、未接続誘導路への進入禁止など）をテストと実行時チェックで保証する |
| NF-06 | 保守性 | モジュール境界（UI / 描画 / コア）を lint で強制する |
| NF-07 | 互換性 | セーブデータにスキーマバージョンを持ち、旧版からの移行処理を用意する |
| NF-08 | アクセシビリティ | 色だけに依存しない状態表示（アイコン・パターン併用）、UI拡大率設定 |
| NF-09 | 可観測性 | デバッグオーバーレイ（論理グラフ・予約状況・状態名）とイベントログ |

## 5. 制約・前提

- 本ゲームは**ゲーム向けの簡略化モデル**であり、実運用の判断に用いることはできない。ゲーム内およびドキュメントにその旨を明記する。
- 航空会社名・機種名は架空とする（例: 「SkyLine Air」「AeroJet 320 相当の M 級機」など）。
- 空中の航空機は「進入待ちキュー」「出発後の離脱」として抽象化し、空域の管制は扱わない。

## 6. 用語集

| 用語 | 本プロジェクトでの意味 |
|------|----------------------|
| タイル | マップの最小配置単位（1タイル = 一辺 25m 相当、[02_game_spec.md](02_game_spec.md) 参照） |
| 建設レイヤー | プレイヤーが配置した施設の「見た目・配置」データ |
| 論理モデル / 論理グラフ | 建設レイヤーから生成される通行可能性・接続関係のデータ（航空機用のエアサイドグラフ、旅客用の処理ネットワーク等） |
| エアサイド | 航空機が走行する側（滑走路・誘導路・エプロン） |
| ランドサイド | 一般車両・旅客がアクセスする側（道路・カーブサイド・ターミナルの非制限区域） |
| スポット | 駐機スポット。1機のみ占有可能 |
| ゲート | ターミナル側の搭乗口。1つ以上のスポットに紐付く |
| ホールディングポイント | 滑走路手前の停止位置。滑走路占有の許可なしに越えられない |
| ターンアラウンド | 到着から出発までのスポットでの地上支援作業全体 |
| GSE | 地上支援車両（Ground Support Equipment） |
| ティック | シミュレーションの1ステップ（1ゲーム秒） |
| 旅客グループ | 同一便・同一行程の旅客をまとめたシミュレーション単位（[04](04_operations_passenger_spec.md) 参照） |
| OTP | 定時運航率（On-Time Performance） |
