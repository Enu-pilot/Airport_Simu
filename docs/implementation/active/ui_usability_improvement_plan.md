## 2. 目的・対象範囲

### 目的
- よく使う操作をワンクリック（またはキー 1 つ）にし、画面のどこに何があるかを分類で直感的に分かるようにする。
- 表以外は画面スクロールなしで機能の入口がすべて見える状態にする（表・一覧のスクロールは許容）。

### 対象
建設画面のツールボックス・下部パネル、経営画面の区分、運航画面の上段ナビ・左列、ショートカットとその案内。

### 非目標
- シミュレーション・保存形式・計算結果の変更（UI の配置と入口だけを変える）。
- 3D 表示・管制官（ATC）画面の再設計。

## 3. 設計方針（改善案）

### A. ワンクリック配置（U5）
- **クイックバー**: 地図の上端に「最近使ったツール 6 個＋ピン留め」を横並びで常時表示する。ツールを選ぶと先頭に入り、右クリックでピン留め。保存先は opsPrefs と同じ localStorage（プロジェクトには入れない）。
- **ツール検索**: ツールボックス上端に検索欄（`/` キーでフォーカス）。「保安」「ゲート」など部分一致で全カテゴリから絞り込み、Enter で選択。
- カテゴリの折りたたみは維持し、**直近に使ったカテゴリは開いたまま**にする（現状は選択中ツールのカテゴリだけが開く）。

### B. ショートカットの拡充と発見性（U6・U7）
- 既存キー（docs/06 §4.1.1）と衝突しない範囲で追加する案:

  | キー | 建設モード | 備考 |
  |---|---|---|
  | `W` | 滑走路（rUnWay の W） | R は回転で使用中 |
  | `T` / `P` | 誘導路 / スポット | 既存 |
  | `O` | エプロン | |
  | `Q` | ゲート | G はグリッド表示で使用中 |
  | `H` | ターミナル（建物） | |
  | `U` | 道路・交通網 | |
  | `Shift+数字` | クイックバーの 1〜6 番目 | 数字単独は階の切替で使用中 |
  | `?` | ショートカット一覧を開閉 | |

- **ショートカット一覧パネル**（`?` とトップバーのボタン）: 建設／運航で切り替わる表。`src/editor/shortcuts.ts` の対応表（TOOL_FOR_KEY・OVERLAY_TOGGLES・LEVEL_FOR_DIGIT_KEY）から生成し、仕様と表示がずれないようにする。
- ツールボタンの右端にキーを小さく表示（例: 「誘導路 T」）。title にもキーを含める。

### C. 分類と重複の整理（U2・U3・U4）
- **建設画面の下部 10 タブを廃止**し、経営画面（全画面ボード）に一本化する。下部は「24 時間タイムライン＋選択中施設の要点」だけにして地図を縦に広げる。建設中に経営情報を見る導線はトップバーの「経営」と、レールの経営ボタン（既存）。
- **運航画面の上段 18 ボタンを 5 群に分類**し、群ごとのドロップダウン（または 1 段のセグメント＋2 段目）にする:
  - 運航: 運航表・イベント・天候・障害
  - 旅客・施設: ターミナル・手荷物・アクセス・配置チェック
  - 地上: 地上支援
  - 経営: 運航計画・経営・航空会社・目標・運航記録・分析
  - 管理: 拡張計画・機種カタログ・シナリオ・プロジェクト
- **経営画面の区分を 4 群に再分類**: 「需要と計画（運航計画・契約・航空会社・乗継）」「施設と能力（空港能力・空港チェック・拡張計画・**夜間整備・工事**）」「お金（収支・財務・アクセス料金）」「記録と管理（分析・履歴・目標・シナリオ・機種カタログ・プロジェクト）」。Work Order は「施設と能力」へ移す（U4）。

### D. スクロールの削減（U1・U8）
- 経営「空港能力」は上段に**ボトルネック上位 5 件だけ**を出し、詳細表は分野タブ（滑走路／スポット／旅客処理／地上支援／アクセス）に分けて 1 画面に収める。表の中のスクロールは許容。
- 運航左列はカード（運航状況・KPI・表示モード・性能計測）を**折りたたみ可能**にし、既定では「運航状況・速度・表示モード」だけ開く。
- 1366 幅向けに、トップバーの補助ボタン（3D・履歴・1 日スキップ・日の設定）を「⋯」メニューへ収める。

## 5. 互換性・リスク
- 保存形式・SIM_MODEL_VERSION・シミュレーション結果への影響なし（UI のみ）。
- UX-7 は利用者の慣れた導線を変えるため、PO 判断が必要。代替案は「下部タブを残し、既定で折りたたむ」。
- キー追加（UX-2）は将来の機能キーと衝突しうるため、割当表を docs/06 §4.1.1 に一本化する。

## 8. 進捗・計画との差分
- 2026-11-23: 改善案を作成。U1 の「枠外へのはみ出し」だけは不具合として性能改善 第8弾の作業で修正済み（`.bottom`・`.tab-body` にスクロール枠）。
- 2026-11-24: PO 指示「全て導入」で UX-1〜8 を実装。計画との差分:
  - UX-3 のクイックバーは「地図の上端」ではなくツールボックスの上端に置いた（地図の操作領域を狭めないため。ツール検索と並べて 1 か所にまとめた）。
  - UX-7 は「下部タブを残して畳む」代替案ではなく廃止を採用。ただし従来の `tab-*` を 1 行の「経営への近道」として残し、押すと経営ボードの該当区分を全画面で開く（内容の正本は経営ボードだけ）。
  - UX-8 の「運航左列の折りたたみ」は、既存のカード（本日の KPI 等）が既に折りたたみ式だったため、新たに折りたたむのは使用頻度の低い「ターミナル内部の表示」（既定で閉じる）だけにした。速度・運航状況・便の追加・表示モードは常に見える。
