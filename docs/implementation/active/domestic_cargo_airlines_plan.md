> 正本: 本書は計画・進捗の正本。貨物の基盤仕様は 5-12（[貨物計画](cargo_operations_plan.md)）と docs/42 §3.4 を正とし、本書は会社・機材カタログの拡充分だけを扱う。

## 1. 現状と課題

- 貨物の運航基盤（需要・契約・上屋・収支・格連携）は 5-12 で実装済みだが、国内線の貨物便を実際に飛ばせる会社・機材のカタログが不足している。
- 既存の貨物関連データ: ANA（NH）は `cargoFleet: B777F / B767-300F`、JAL（JL）は `B767-300F` を保持。日本貨物航空（NCA、KZ）は国際線のみ（自社運航の国内定期貨物便はないため国内線には使えない）。
- 2026-11-20 の実在調査の結論: 成田発着の国内貨物専用機を現在運航しているのは実質スプリング・ジャパン（ヤマト運輸、成田−新千歳・北九州・那覇、A321P2F ×3、2024 年開始）だけだった。ANA Cargo の国内専用機は 2020 年以降運休（ベリーへ移行）し専用機は国際線中心、JAL カーゴの専用機も国際線のみ（国内投入は想定段階で開始未確認）。推測で会社・路線を足さない方針どおり、実装対象はスプリング・ジャパンに絞られた。

## 2. 目的・対象範囲

### 目的
- 成田を中心に国内各空港へ就航している貨物航空会社とその機材を洗い出し、カタログへ実装して国内貨物便の提案・契約が成立するようにする。

### 対象
- 国内で貨物専用機を運航する会社とその機材（`cargoFleet` の拡充・必要な機種の追加）。

### 非目標（PO の線引き）
- ベリー（旅客便の貨物室）のみの会社は対象外。
- 外国籍会社はカボタージュにより国内線を運航できないため、国内線の対象外（国際貨物は既存の扱いのまま）。

## 3. 設計方針

- 実在データに基づき、会社ごとに拠点・就航地・機材を確認してから追加する。推測で会社・路線を作らない。
- 架空会社の制限（2026-F）とは独立に扱う（本計画は実在会社のみ）。
