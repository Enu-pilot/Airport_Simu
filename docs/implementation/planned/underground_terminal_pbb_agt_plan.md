> 更新日: 2026-11-20

## 1. 現状と課題

- 地下単独で置ける施設は駐車場・従業員駐車場・鉄道駅のみ（`UNDERGROUND_FACILITY_KINDS`）。ターミナルは地下単独にできず、建物の最下階・最上階を独立に選ぶこともできない。ターミナルエリア自体は B3 まで置ける。
- PBB はコードに存在しない。ゲート施設の `boardingMode`（contact/bus）が搭乗橋の有無を暗黙に扱っている。
- AGT は未実装。現行の TerminalTransitLink は AGT ではない（docs/34 の明記どおり）で、駅・路線・運行のモデルがない。
- 階の定義は 1 層 = 6m（`DEFAULT_LEVEL_HEIGHT_M`）で既に存在するが、高層連絡通路の既定（標高 36m・クリアランス 33m）は「未知機種は尾翼高 30m」という全体基準から来ており、実際に下を通る機種に対して過大。

## 2. 目的・対象範囲

### G: 地下だけの建物
- 建物の最下階・最上階を独立に選択可能にし（例: B2〜B1、B1 のみ、B1〜3F）、地下単独のターミナル／コンコースを許可する。真上にエプロン・スポット等を置ける想定とする。
- 地上の出入口を持たない建物は、地下通路・AGT 等で接続されていなければ到達不能の警告を出す。
- 設計上の扱い: 型の追加はしない。`UNDERGROUND_FACILITY_KINDS` へ 'terminal' を追加し、`floorRangeMin/Max` を新設する。あわせて `facilityVerticalRange` の地下ターミナル高さに関する現行の不整合を修正する。

### H: 搭乗ゲートと PBB の分離
- ゲートはターミナル側の待合・搭乗管理ノード（旅客グラフのノード）として残し、PBB は機体ドアへつなぐ物理設備として新施設種別 `boardingBridge` を新設する。
- PBB は型式（1 トンネル／2 トンネル／A380 アッパーデッキ対応の 3 種）、対応ドアシル高（SizeClass から導くゲーム値）、搭乗速度を設計可能にする。1 トンネルの速度は現行定数と一致させ、既存レイアウトの挙動を変えない。
- **PBB の本数を 1 本／2 本で設定可能にする**（PO 追加要望 2026-11-20）。2 本は大型機に対応できるものとする（1 本でも対応は可能だが、2 本で搭乗効率が上がる扱いを設計する）。
- PBB がないスポットはバス／徒歩搭乗となり、遅く・評価が下がる扱いとする。既存の contact/bus は「PBB あり／バス」へ読み替える互換を持つ。
- **既存セーブにある搭乗ゲートは、すべて PBB に置き換わる**ようにする（PO 指示 2026-11-20。移行の具体方式は着手時に設計し、ゴールデン不変の受入条件との両立を確認する）。

### I: AGT
- AGT は別モデル（`AgtSystem` / `AgtSegment` ＋新施設 `agtStation`）として新設する。駅・路線に加え、車両定員・運転間隔・停車時間から能力と待ち時間を導く運行モデルを持つ。
- 駅はターミナル設計 Workspace で配置する（5-18 T10 と合流）。接続していない駅は利用不可として扱う。

### J: 階層定義の統一と連絡施設の複合編集
- J-1（先行）: 1 層 = 6m の定義を全表示で併記する（例: 「2F（床 +6m／地図階層 +1）」）。高層連絡通路の階は、宣言方式（`crossingMaxCode`: 下を通る最大機種）から導出する — 尾翼高＋余裕 3m を 6m 層へ切り上げ（コード C 機 → 18m／4F 相当、E 機 → 24m／5F 相当、A380 → 30m／6F 相当）。宣言が欠落した場合は従来の既定と完全一致させる。
- J-2: 連絡通路前後の垂直移動ノード（エスカレーター等）と通路段を「1 つの連絡施設」として設計画面で編集できるようにする。実装は既存部品のグルーピング記録であり、旅客グラフへは 3 区間に展開する（sim の挙動は変えない）。

### 非目標
- 保存形式の版上げと `SIM_MODEL_VERSION` の変更。全機能とも任意項目の追加で `SCHEMA_VERSION 3` を維持し（新項目を含むファイルのみ formatVersion 9）、運航ゴールデン全件不変を受入条件とする。

## 3. 設計方針

- 推奨実装順: **J-1 → G → H → J-2 → I**（階の物差しを先に揃え、地下・PBB・複合編集・AGT の順に積む）。
- CDG 型の再現レシピ: 本館 B1 の駅 ⇔ 地下 AGT ⇔ サテライト（地下単独コンコース＋地上の小規模ピア）。
