# 翌朝持ち越し便の出発準備完了判定 修正計画

> 状態: **planned（計画済み・未実装）**
> 作成日: 2026-11-18
> 対象: 夜間滞泊機を翌朝に置き直した後、地上作業が完了しても出発しない不具合

## 1. 目的

夜間滞泊から翌朝へ持ち越された便が、必要な地上作業・旅客搭乗を終えた後、通常便と同じ状態遷移でプッシュバック・地上走行・離陸できるようにする。

本計画は、既存の夜間滞泊仕様を変更するものではなく、作業省略時の出発準備完了判定と、その回帰テストを修正する。

## 2. 現状調査

### 2.1 実装済みの処理

- `src/core/sim/overnight.ts` の `materializeCarryOver()` は、翌日の運航開始時に記録済みの機体をスポットへ置き直し、合成到着便と翌朝の出発便を生成する。
- 置き直した機体の地上作業生成では、到着旅客・到着手荷物が存在しないため、`createTurnaroundTasks(sim, ac, { skip: ['deplane', 'unload'] })` として降機・荷下ろしを省略する。
- `src/core/sim/simulation.ts` は `allTurnaroundDone(state, ac.id)` が true になった機体を出発準備完了として扱う。

### 2.2 確認された不整合

現行の `src/core/sim/ground.ts` の `allTurnaroundDone()` は、プッシュバック作業を除いたタスク数が `TURNAROUND_TASKS.length` と完全一致することを要求している。

一方、夜間滞泊機は `deplane` と `unload` の2作業を意図的に生成しない。このため、生成された残りの作業がすべて完了していても、タスク数の一致条件を満たさず、出発準備完了にならない経路が成立する。

これは「省略された作業を未完了として扱う」判定不整合であり、翌朝便がプッシュバックへ進まない症状と整合する。コード修正・再現テストによる確定はこれから行う。

### 2.3 テスト上の不足

- `tests/unit/sim/overnight.test.ts` には翌日便の生成・スポット再配置等の確認があるが、翌朝便が地上作業完了後にプッシュバックし、最終的に離陸するまでの一連の確認が不足している。
- 通常便の全作業必須ケースと、夜間滞泊便の省略作業ありケースを並べた回帰確認が必要。

## 3. 修正方針

1. `allTurnaroundDone()` の完了条件を、固定の全タスク数との一致に依存しない形へ修正する。
2. 省略された作業は「未完了」ではなく「この機体では要求されていない作業」として扱う。
3. ただし、タスクが未生成・欠落した状態を誤って完了扱いにしないこと。タスク生成時の省略情報・必須タスク定義・既存の状態表現を調査し、通常便と夜間滞泊便の両方で必要タスクの存在と完了を判定できる設計にする。
4. 通常便では従来どおり全必須作業が必要であり、作業中・未着手のタスクが1つでもあれば出発準備完了にならない。
5. プッシュバックタスクは出発準備完了判定の対象外とし、既存のプッシュバック開始・完了処理を維持する。
6. 旅客搭乗、搭乗締切、機体・スポット・誘導路・滑走路の制約を迂回せず、既存の通常出発フローを通す。

## 6. 受入条件・テスト

- 通常便: 必須の折り返し作業がすべて完了するまで `allTurnaroundDone()` は true にならない。
- 通常便: いずれかの必須作業が未着手・進行中・失敗状態なら出発準備完了にならない。
- 夜間滞泊便: skip対象の `deplane`・`unload` が存在しなくても、残りの必須作業が完了すれば出発準備完了になる。
- タスク生成漏れ・必須タスク欠落を、誤って全作業完了として扱わない。
- 翌朝便が通常の旅客搭乗条件を満たし、プッシュバックから離陸まで到達する。
- 複数機の持ち越し、スポット競合、地上作業能力不足で不正に出発しない。
- 通常便・既存の運航ゴールデン・決定性に意図しない変更がない。

対象テストを先に実行し、完了後は `npm run typecheck`、`npm run lint`、`npm test`、`npm run build` を実行する。シミュレーションの変更前後でゴールデンと主要 KPI を比較する。既存の期待値・ゴールデンを合格目的で更新しない。

## 7. 互換性・非目標

- 保存形式、`SIM_MODEL_VERSION`、既存データ構造は、必要性が立証されない限り変更しない。
- 夜間滞泊の契約条件・出発時刻・スポット割当・会計仕様は変更しない。
- 地上作業時間や必要人数などのバランス値は変更しない。
- 旅客搭乗や滑走路運用の制約を緩和しない。
- 無関係な地上支援処理のリファクタリングを行わない。
