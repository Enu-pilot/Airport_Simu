# SkyPort

PC ブラウザで動作する空港デザイン・運営シミュレーションゲームです。滑走路・誘導路・スポット・ターミナル・各種設備を配置し、航空機の運航、旅客・手荷物の流れ、地上支援、航空会社との契約を管理します。施設や交通網の配置は、見た目だけでなくシミュレーション上の処理能力と動線に影響します。!



> 本ゲームは娯楽目的の簡略化モデルです。実際の航空管制・航空安全基準への適合を保証するものではありません。

## 主な機能

**Phase 12** — 滑走路を任意の真方位・実長（m）で置ける「自由形」を追加（滑走路ツールのオプション。既定は従来の 8 方向）。実寸の舗装・肩・着陸帯・RESA による判定、
磁気偏角つきの滑走路番号（L/C/R）、平行間隔の警告、交差する滑走路（従属運用）、2D/3D の描画。従来形の舗装は実寸の幅で表示。
設計・参考値は [docs/23](docs/23_runway_design.md)、検証は [docs/26](docs/26_validation_rules.md)、移行・互換性は [docs/27](docs/27_migration_and_compatibility.md)。
参考値はゲーム内の判定であり、実際の安全基準への適合を保証しない。未実装・既知の制限は [docs/10](docs/10_open_issues.md) の M。

**Phase 7〜10** — 具体的な機種・派生型（777-300 と 777-300ER など、メーカー資料で照合した値と出典つき）を航空会社の保有機材・便に割り当て、
機種ごとに座席・手荷物・地上作業・必要な滑走路長・スポットの適合性が変わる。天候・障害（滑走路閉鎖・ゲート故障・車両故障・欠勤・需要急増など）と対応操作。
機種別・航空会社別などの運営分析、ボトルネックの根拠、混雑マップ、シナリオ比較。2D/3D 表示の切り替え（3D の機体は手続き生成）。
プロジェクトの保存・復元（運航中の状態を含む）、機種データの固定と最新カタログとの差分、旧形式の移行。
Phase 1〜6 の建設エディタ、運航、旅客、地上支援・手荷物、運航計画・経営、空港アクセス・拡張はそのまま使える。

**フェーズ 4（2026-11-18）** — 格による機能の解放、夜間滞泊・拠点航空会社・整備の周期、国際線（出入国審査・税関・兼用ゲート）、乗継旅客・乗継手荷物・最小乗継時間・バンク、道路/線路の区間能力モデルを追加した。すべて任意（opt-in）で、使わないセーブの結果は変わらない。仕様は [docs/44](docs/44_hub_and_international.md)。
ルールは docs/11〜21（下表）。いずれもゲーム用の簡略化モデルで、金額はゲーム内通貨 cr（実在の料金・費用とは無関係）。
貨物輸送は部分実装です。貨物需要・契約/便計画・機種容量・上屋と荷役能力・収支計算・保存互換・格解放連携の土台がありますが、実便化・貨物専用機・日報・道路区間競合などは未実装です。詳細は [貨物実装計画](docs/implementation/active/cargo_operations_plan.md) を参照してください。
未実装の機能・既知の制限は [docs/10](docs/10_open_issues.md) の K・Q（自動最適化、風向運用、除雪/防除氷など）を参照。基盤完成後に再検討する項目の実装計画は [実装計画一覧](docs/implementation/README.md#基盤完成後に再検討する個別計画) にまとめています。

## 使い方

```bash
npm ci
npm run dev          # 開発サーバー（http://localhost:5173）
npm run typecheck    # TypeScript の型検査
npm run lint         # ESLint
npm test             # Vitest 単体テスト
npm run test:e2e     # Playwright E2E テスト
npm run build        # 型検査 + 本番ビルド（dist/）
```

## 操作と保存

- 左クリック／ドラッグで選択・移動・配置、右ドラッグ・中ドラッグ・Space+ドラッグでパン、ホイールでズームします。
- 誘導路・道路はクリックで頂点を追加し、ダブルクリック・Enter・右クリックで確定します。
- R / Ctrl+D / Delete は回転 / 複製 / 削除、Ctrl+Z / Ctrl+Shift+Z（または Ctrl+Y）は元に戻す / やり直しです。
- 3D 表示ではドラッグで回転、右ドラッグでパン、ホイールでズームできます。
- プロジェクトはブラウザ内に保存されます。端末・ブラウザをまたぐバックアップには JSON の書き出し・読み込みを使用してください。形式・移行の詳細は [docs/21](docs/21_save_format.md) と [docs/27](docs/27_migration_and_compatibility.md) を参照してください。
